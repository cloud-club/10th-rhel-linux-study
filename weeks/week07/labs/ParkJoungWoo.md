# 정답

## 프로세스 우선순위 (nice, renice, tuned-adm) 실습 해설

### 1. 다음 중 가장 높은 CPU 우선순위를 뜻하는 nice 값은 무엇입니까?

**정답:** **c.** `-20`

* **핵심 포인트:** nice 값의 범위는 **-20 ~ 19**이고 기본값은 **0**입니다. nice는 '착한' 정도라서, 값이 클수록 다른 프로세스에게 CPU를 **양보**합니다. 따라서 **숫자가 작을수록 우선순위가 높습니다.** 숫자와 우선순위가 거꾸로라는 점이 함정입니다.
* **선지 설명:**
* **a.** `19`: 가장 많이 양보하는 값, 즉 **가장 낮은** 우선순위입니다.
* **b.** `0`: 대부분의 프로세스가 시작할 때 갖는 **기본값**입니다.
* **d.** `20`: nice 값의 범위(-20 ~ 19)를 벗어난 값입니다. 참고로 `top`의 **PR** 칸은 `20 + NI`로 계산되어 nice 0인 프로세스가 PR 20으로 표시됩니다.

---

### 2. 실행 중인 PID 1234 프로세스의 nice 값을 15로 바꾸는 명령은 무엇입니까?

**정답:** **b.** `renice -n 15 -p 1234`

* **핵심 포인트:** **새로 시작**하는 프로그램은 `nice`, **이미 실행 중**인 프로그램은 `renice`를 사용합니다. 실행 중인 프로세스는 이름 대신 번호(PID)로 가리키며 `-p` 옵션을 씁니다.
* **선지 설명:**
* **a.** `nice -n 15 1234`: `nice`는 뒤에 오는 것을 **실행할 명령**으로 해석합니다. 1234라는 명령을 nice 15로 실행하려다 실패합니다.
* **c.** `nice -p 1234 -n 15`: `nice`에는 `-p` 옵션이 없습니다.
* **d.** `top -n 15 -p 1234`: `top`의 `-n`은 **화면 갱신 횟수**, `-p`는 **지켜볼 PID**입니다. nice 값을 바꾸지 않습니다. (top 실행 중 `r` 키를 누르면 renice 기능을 쓸 수 있습니다.)

---

### 3. 일반 사용자 student가 nice 값 10으로 실행 중인 자신의 프로세스에 대해 할 수 있는 작업은 무엇입니까?

**정답:** **c.** nice 값을 15로 올리기

* **핵심 포인트:** 일반 사용자는 자기 프로세스의 nice 값을 **올리는 것(더 양보하기)** 만 할 수 있습니다. 값을 **내리는 것(새치기하기)** 은 root만 가능합니다. 한 번 올린 값을 원래대로 되돌리는 것도 "내리기"이므로 root 권한이 필요합니다.
* **선지 설명:**
* **a.** 5로 낮추기: 값을 내리는 작업이므로 `Permission denied`가 발생합니다.
* **b.** 0으로 되돌리기: 원래 값으로 돌아가는 것이라도 "내리기"에 해당하므로 일반 사용자는 할 수 없습니다.
* **d.** -5로 낮추기: 음수 값은 우선순위를 크게 높이는 작업이므로 root만 가능합니다.

---

### 4. 다음 중 현재 시스템에 가장 알맞은 tuned 프로파일을 추천받는 명령은 무엇입니까?

**정답:** **c.** `tuned-adm recommend`

* **핵심 포인트:** `tuned-adm recommend`는 하드웨어와 환경(물리 서버, 가상 머신 등)을 보고 알맞은 프로파일 **이름**을 알려 줍니다. 시험에서 "권장 프로파일을 적용하라"는 문제는 **recommend → profile → active** 3단계로 풉니다.
* **선지 설명:**
* **a.** `tuned-adm list`: 선택 가능한 **모든 프로파일 목록**을 보여 줍니다.
* **b.** `tuned-adm active`: **현재 적용 중인** 프로파일을 확인합니다.
* **d.** `tuned-adm verify`: 현재 프로파일의 설정이 시스템에 **제대로 적용되었는지 검사**합니다.

---

### 5. 가상 머신에 맞는 tuned 프로파일을 적용하는 올바른 명령은 무엇입니까?

**정답:** **b.** `tuned-adm profile virtual-guest`

* **핵심 포인트:** 프로파일 변경은 `tuned-adm profile 프로파일이름` 형식입니다. 이 설정은 **재부팅 후에도 유지**됩니다. 가상 머신 안의 리눅스는 `virtual-guest`(손님), 가상 머신을 돌리는 호스트는 `virtual-host`(집주인)를 사용합니다.
* **선지 설명:**
* **a.** `tuned-adm set`: `set`이라는 하위 명령은 존재하지 않습니다.
* **c.** `tuned-adm active virtual-guest`: `active`는 현재 프로파일을 **확인**만 하는 명령입니다.
* **d.** `tuned-adm use`: `use`라는 하위 명령은 존재하지 않습니다.
