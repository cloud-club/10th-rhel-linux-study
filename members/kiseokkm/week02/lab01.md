## 문제 1

숫자 모드로, `report.txt`를 소유자는 읽기/쓰기, 그룹과 기타는 읽기만 가능하게 설정하라.

### 답안

```bash
chmod 644 report.txt
```

### 간단 코멘트

`6 = rw-`, `4 = r--`, `4 = r--`이므로 소유자는 읽기/쓰기, 그룹과 기타 사용자는 읽기만 가능합니다.

---

## 문제 2

`project/` 디렉터리의 소유자를 `kim`, 소유 그룹을 `dev`로 한 번에 바꿔라.

### 답안

```bash
chown kim:dev project/
```

### 간단 코멘트

`chown 소유자:그룹 대상` 형식으로 소유자와 소유 그룹을 한 번에 변경할 수 있습니다.

---

## 문제 3

여러 사용자가 함께 쓰는 `/shared/dropbox`에서, 각자 자기 파일만 삭제할 수 있도록 설정하라.

### 답안

```bash
chmod +t /shared/dropbox or 권한까지 함께 지정하는 경우는 chmod 1777 /shared/dropbox
```

### 간단 코멘트

Sticky Bit를 설정하면 여러 사용자가 디렉터리를 함께 사용하더라도 일반 사용자는 다른 사용자의 파일을 삭제하지 못합니다.
