## 문제 1

숫자 모드로, `report.txt`를 소유자는 읽기/쓰기, 그룹과 기타는 읽기만 가능하게 설정하라.

### 답안

```bash
chmod 644 report.txt
```

### 간단 코멘트

`rw- = 4+2 = 6`, 나머지는 `r-- = 4`입니다.

---

## 문제 2

`project/` 디렉터리의 소유자를 `kim`, 소유 그룹을 `dev`로 한 번에 바꿔라.

### 답안

```bash
chown kim:dev project/
```

### 간단 코멘트

`chown 사용자:그룹` 형식이면 `chgrp`를 따로 안 써도 됩니다. 안쪽 파일까지 바꾸려면 `-R`을 붙입니다.

---

## 문제 3

여러 사용자가 함께 쓰는 `/shared/dropbox`에서, 각자 자기 파일만 삭제할 수 있도록 설정하라.

### 답안

```bash
chmod 1777 /shared/dropbox
```

### 간단 코멘트

Sticky Bit입니다. 파일 삭제는 파일 권한이 아니라 그 파일이 들어 있는 디렉터리의 쓰기 권한으로 결정되기 때문에, 공용 디렉터리에서는 남의 파일도 지워집니다. Sticky Bit를 붙이면 파일 소유자와 root만 지울 수 있습니다.

`ls -ld /tmp`로 보면 `drwxrwxrwt`로 맨 끝이 `t`입니다.

# 선택 작성

## 배운 점

- 삭제 권한이 파일이 아니라 디렉터리에 달려 있다는 점이 제일 헷갈렸습니다.
- 숫자 모드는 권한을 통째로 덮어쓰고 기호 모드는 해당 부분만 더하거나 빼기 때문에, 기존 설정을 유지해야 할 때는 기호 모드를 써야 합니다.
